========================================
  棉云哨 项目交付说明
========================================

【项目位置】
D:\AI测试\whitefly\

【一键启动】
双击 "启动.bat" 即可运行
服务地址：http://localhost:8501
局域网地址：http://10.189.219.73:8501

【答辩现场使用】
1. 把整个 whitefly 文件夹拷贝到答辩电脑上
2. 确认答辩电脑已安装 Python 3.14（或提前装好）
3. 双击启动.bat，浏览器自动打开
4. 评委提问时直接演示，点击"低/中/高虫量示例"快速展示

【远程分享】
需要公网访问时：
1. 安装 ngrok：https://ngrok.com/download
2. 注册账号：https://dashboard.ngrok.com/signup
3. 运行：ngrok http 8501
4. 把生成的 https://xxx.ngrok.app 发给对方

【核心功能】
- AI识别：上传黄板照片，YOLO模型自动检出烟粉虱数量
- 气象联动：真实天气数据（阿拉尔/喀什/阿克苏/和田）
- 风险决策：虫量+气象综合评估，给出防控建议
- 会话管理：像AI助手一样新建/切换/重命名监测会话
- 历史记录：所有识别结果自动存档，可查趋势

【技术栈】
Python 3.14 + YOLOv8 (Ultralytics) + Streamlit + Open-Meteo API
无需硬件，纯软件方案
